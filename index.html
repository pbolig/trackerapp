Primera vez · Configurá la base de datos compartida — solo se hace una vez por dispositivo
1
Ir a console.firebase.google.com con una cuenta Google y crear un proyecto nuevo (ej: trackerapp-gdti). Podés desactivar Analytics.
2
Dentro del proyecto: Realtime Database → Crear base de datos. Elegir región us-central1 e iniciar en modo de prueba.
3
Ir a Configuración del proyecto ⚙ → General → Tus apps → agregar app Web </>. Copiar los valores del objeto firebaseConfig y pegarlos abajo.
4
Cada integrante del equipo ingresa estas mismas credenciales la primera vez que abre la app. Los datos son compartidos entre todos.
CREDENCIALES FIREBASE
API Key
Auth Domain
Database URL
Project ID
App ID
Esta configuración se guarda solo en este navegador. Cada integrante la ingresa una sola vez.
